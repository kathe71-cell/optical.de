# optical.de — Standalone Portal & Pitch Project

Unabhängiges Verbraucher- & Preisvergleichsportal für Kontaktlinsen, Pflegemittel und Optiker-Eigenmarken-Entschlüsselung.

## Project Structure
- `src/pages/Home.jsx`: Interactive landing page, Eigenmarken Decoder, Multi-merchant comparison table & Unit Economics Calculator.
- `public/`: Assets & Favicon.
- `dist/`: Vite production bundle.

## Commands
- `npm run dev`: Start local development server
- `npm run build`: Build production bundle
- `npx vercel --prod`: Deploy to Vercel production (`https://optical-de.vercel.app`)
